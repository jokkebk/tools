# Pumpkin artwork

Created with the built-in imagegen tool. Existing Fluffy artwork was the style reference for the clean portrait; the resulting clean portrait was the edit target for the dirty version. Both outputs were resized to 800 × 1200 and encoded as AVIF to match the existing assets.

Files: `monster4_clean.avif`, `monster4_dirty.avif`.

## Clean portrait prompt

Use case: stylized-concept. Asset type: portrait monster art for a toddler toothbrushing game. Input image is a STYLE AND FRAMING REFERENCE only, not an edit target. Create one new friendly Halloween monster named Pumpkin: cuddly fluffy orange fur, rounded pumpkin-like body, a little green pumpkin stem and leaf on its head, small soft lavender bat wings, enormous kind glossy eyes, waving one little paw, sitting with feet visible. A very large open happy grin with two clearly visible rows of broad WHITE CLEAN human-like rounded teeth, easy for a toddler to brush, centered around 48% of image height. Match the reference's soft pastel storybook painted rendering, gentle light, full-body front-facing portrait on a softly painted pale lavender/cream background with a few small pumpkins. Portrait 2:3 framing with face in the central region, full body centered. Cute and comforting, suitable for a two year old at bedtime, no scary elements, no fangs, no lettering, no text, no watermark. Save the generated image so it can be used as a project asset.

## Dirty teeth edit prompt

Use case: precise-object-edit. Edit target: the supplied orange fluffy pumpkin Halloween monster portrait. Create the dirty-teeth version for an interactive tooth brushing game. Change ONLY the visible white tooth surfaces: add pale yellow plaque and scattered small brown/olive food speckles across both rows of teeth. Keep the teeth shapes, mouth, lips, gums, eyes, face, fur, paw, wings, background, colors and every other part of the picture perfectly identical to the original, pixel aligned at the same 1024x1536 portrait size. No other changes at all. Toddler-friendly mild dirt, no scary cavities, no text or watermark.
